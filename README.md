# Global Warming Data Analysis

## Objective
This project investigates global warming using publicly available climate datasets.

The analysis includes:
- Global land and ocean temperature trends
- Atmospheric CO₂ concentration
- Solar irradiance
- Volcanic activity
- Correlation and statistical analysis
